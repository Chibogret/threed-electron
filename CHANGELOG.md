# Changelog

## 1.0.0 - 2025-10-29

### Added

*   Initial release of the Hardware Supplies Pricebook application.
*   CRUD functionality for pricebook items (Article, Unit, Unit Cost, Sale Price).
*   Removed Margin display from the main table.
*   Removed Target Margin control and "Suggest Price" functionality.
*   Replaced Price Calculator with a Shopping Cart feature.
*   Search and sort capabilities for the item table.
*   CSV import and export with robust parsing and validation.
*   Persistence using `localStorage` (with Electron file storage adapter).
*   Keyboard shortcuts: `Cmd/Ctrl+N`, `Cmd/Ctrl+F`, `Cmd/Ctrl+I`, `Cmd/Ctrl+E`.
*   Desktop polish: Window size/position persistence, app menu (File, Edit, Help), About dialog.
*   Basic styling.
